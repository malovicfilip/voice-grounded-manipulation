# Local development setup

This project uses WSL 2 with Ubuntu 24.04 (Noble) for ROS 2 development,
language logic, and tests. Isaac Sim and GPU-heavy perception are intentionally
reserved for a temporary cloud GPU workstation.

The commands below apply only to the Ubuntu 24.04 WSL distribution. Do not run
them in the separate Ubuntu 26.04 distribution.

## Install ROS 2 Jazzy

ROS 2 Jazzy supports Ubuntu 24.04 as a Tier 1 platform. Follow the official
[ROS 2 Jazzy Ubuntu installation guide](https://docs.ros.org/en/jazzy/Installation/Ubuntu-Install-Debs.html)
and use a UTF-8 locale.

Verify the locale:

```bash
locale
```

Enable Ubuntu Universe and install the current ROS repository package:

```bash
sudo apt install software-properties-common curl
sudo add-apt-repository universe

export ROS_APT_SOURCE_VERSION="$(curl -s https://api.github.com/repos/ros-infrastructure/ros-apt-source/releases/latest | sed -n 's/.*"tag_name": "\([^"]*\)".*/\1/p')"
curl -L -o /tmp/ros2-apt-source.deb "https://github.com/ros-infrastructure/ros-apt-source/releases/download/${ROS_APT_SOURCE_VERSION}/ros2-apt-source_${ROS_APT_SOURCE_VERSION}.noble_all.deb"
sudo dpkg -i /tmp/ros2-apt-source.deb
```

Update Ubuntu, then install ROS and its development tools:

```bash
sudo apt update
sudo apt upgrade
sudo apt install ros-jazzy-desktop ros-dev-tools
```

Initialize `rosdep` once per WSL distribution, then update its Jazzy index as
the regular user:

```bash
sudo rosdep init
rosdep update --rosdistro jazzy
```

MoveIt is deliberately excluded from this setup and will be installed only
when motion-planning integration begins.

## Verify ROS communication

Source ROS in each terminal before running ROS commands:

```bash
source /opt/ros/jazzy/setup.bash
```

Run the official C++ publisher in one terminal:

```bash
ros2 run demo_nodes_cpp talker
```

Run the official Python subscriber in a second sourced terminal:

```bash
ros2 run demo_nodes_py listener
```

The listener should print `I heard` followed by the messages emitted by the
talker. Stop both nodes with `Ctrl+C`.

## Build the workspace

From the repository root:

```bash
source /opt/ros/jazzy/setup.bash
cd ros2_ws
rosdep install --from-paths src --ignore-src --rosdistro jazzy -r -y
colcon build --symlink-install
source install/setup.bash
```

`build/`, `install/`, and `log/` are generated by `colcon` and ignored by Git.
Use `--symlink-install` so changes to Python files and other non-compiled
resources are reflected without copying them into the install space after
every edit.
